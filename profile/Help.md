# Github Related

## Cloning a Project

This is a step by step tutorial on how to clone a Project

1. Download [Github CLI](https://cli.github.com/) and authenticate
2. Go to the project you want to clone
3. Press the Green Code Button
4. Choose Local and Github CLI
5. Copy the command
6. Open Terminal (Mac OS/Linux), or CMD/Powershell (Windows)
7. We suggest to not clone it into the root folder, so please type in `cd documents`
8. Paste the copied command and press enter to execute
9. Now you have copied the repository into your folder, it should be under whatever the repository name is

# Git

## Downloading

Git is a open source version managing system that we use for our projects\
Please download [Git](https://git-scm.com/install/mac) before you start with working on projects

## Pushing and Pulling

Please make sure you have downloaded Git according to the [Downloading](profile/Cloning.md#downloading)

### Pushing

Terminal: `git push`

We suggest to push using in IDE or extra software, as pushing and commiting using terminal needs a decent amount of commands and is hard to edit commit details

### Pulling

Terminal: `git pull`

Branch specific: `git pull 'remote_name' 'branch_name'`
