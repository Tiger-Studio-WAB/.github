## Hallo 👋

Willkommen in der Organisation Tiger Studio WAB.

## Beitreten

Wenn du WAB-Schüler:in bist und diesem Passion Club beitreten möchtest, folge diesen Schritten:

1. Lege ein GitHub-Konto an, falls du noch keines hast.
2. Bitte eine Organisations-Admin um eine Einladung in diese Organisation.
3. Installiere die [GitHub CLI](https://cli.github.com/), damit du Repositories im Terminal bearbeiten kannst.
4. [Klone das Projekt-Repository](Help.de.md#ein-projekt-klonen), sobald du Zugriff hast.

## Regeln für alle Repositories

1. Mache in keinem Repository einen Force-Push. Force-Pushes können die Arbeit anderer überschreiben und verlorene Änderungen schwer wiederherstellen.
2. Committe oder pushe ungetesteten Code nicht direkt auf `main`. Arbeite zuerst auf einem Branch, teste deine Änderungen und öffne dann einen Pull Request.
3. KI-Werkzeuge sind erlaubt, aber du bleibst verantwortlich: Code prüfen, Fehler beheben und verstehen, was committed wird.
4. Speichere keine sensiblen Informationen in einem Repository, sofern eine Admin das nicht ausdrücklich genehmigt hat. Dazu gehören API-Keys, Passwörter, Tokens und private Zugangsdaten.
5. Gib bei jedem Asset in einem Projekt die Herkunft an. Beispiele: eigene Arbeit, eine itch.io-Urheberin / ein itch.io-Urheber, Open-Source-Assets oder KI-generierte Inhalte.

## Hilfreiche Hinweise

- Wenn etwas unklar ist, frage eine Admin, bevor du Änderungen machst.
- Halte Commits fokussiert und beschreibend, damit Reviews leichter fallen.
- Im Zweifel speichere deine Arbeit lokal oder auf einem Branch, bevor du größere Edits machst.
