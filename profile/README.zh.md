## 你好 👋

欢迎来到 Tiger Studio WAB 组织。

## 如何加入

如果你是 WAB 学生，并希望加入这个兴趣社团，请按以下步骤操作：

1. 如果还没有 GitHub 账号，请先注册一个。
2. 向组织管理员申请邀请，加入本组织。
3. 安装 [GitHub CLI](https://cli.github.com/)，以便在终端中操作仓库。
4. 获得权限后，[克隆项目](Help.zh.md#克隆项目)仓库。

## 所有仓库通用规则

1. 不要对任何仓库使用 force push。强制推送可能覆盖他人的工作，并导致丢失的更改难以恢复。
2. 不要把未经测试的代码直接提交或推送到 `main` 分支。先建分支，测试你的更改，然后再开 pull request。
3. 可以使用 AI 工具，但你仍需负责审阅代码、修正错误，并理解最终提交的内容。
4. 除非管理员明确批准，否则不要在任何仓库中存放敏感信息。这包括 API 密钥、密码、令牌和私人凭据。
5. 项目中使用的任何素材，都要说明来源。例如：自己的作品、itch.io 创作者、开源素材，或 AI 生成内容。

## 实用提示

- 如果有不清楚的地方，先问管理员，再做更改。
- 提交信息要聚焦、描述清楚，方便他人审阅。
- 拿不准时，先把工作保存在本地或单独分支，再做更大改动。
